# Scripts

This directory contains automation scripts and utilities for Alfina & Mugni's Wedding Website project.

## Script Categories

### 🏗️ Build & Development

Scripts for building, testing, and development workflow automation.

### 🚀 Deployment

Automated deployment scripts for staging and production environments.

### 🧹 Maintenance

Database cleanup, asset optimization, and routine maintenance scripts.

### 📊 Analytics & Monitoring

Scripts for gathering wedding website metrics, guest interaction data, and performance monitoring.

### 🔧 Utilities

Helper scripts for common development tasks, data processing, and project management.

## Usage Guidelines

- All scripts should be executable and well-documented
- Include help text and usage examples in script headers
- Use consistent exit codes (0 for success, non-zero for errors)
- Log important operations and errors
- Follow security best practices for any sensitive operations

## Script Naming Convention

- Use kebab-case for script filenames
- Include descriptive names that indicate the script's purpose
- Add appropriate file extensions (`.sh`, `.js`, `.ts`, etc.)

## Examples

```bash
# Development scripts
./scripts/setup-dev-environment.sh
./scripts/generate-wedding-data.js

# Deployment scripts
./scripts/deploy-staging.sh
./scripts/backup-production.sh

# Utilities
./scripts/optimize-images.sh
./scripts/validate-rsvp-data.js
```
