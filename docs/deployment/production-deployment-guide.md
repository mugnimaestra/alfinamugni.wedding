# Production Deployment Guide

This guide covers the complete deployment process for the Alfina & Mugni wedding website to Cloudflare Pages.

## 🚀 Quick Start

For experienced developers, here's the quick deployment process:

```bash
# 1. Set up admin credentials
npm run admin:setup

# 2. Apply database migrations
npm run db:migrate

# 3. Run production tests
npm run test:production

# 4. Deploy to production
npm run deploy
```

## 📋 Prerequisites

Before deploying to production, ensure you have:

- [x] Node.js 18+ installed
- [x] Cloudflare account with Pages enabled
- [x] Cloudflare Wrangler CLI installed (`npm install -g wrangler`)
- [x] Domain name (optional, for custom domain)
- [x] Email service account (Resend recommended)
- [x] Admin credentials ready

## 🔧 Environment Setup

### 1. Install Dependencies

```bash
npm ci
```

### 2. Configure Cloudflare Authentication

```bash
wrangler auth login
```

### 3. Set Up Admin Account

Run the admin setup script to generate secure credentials:

```bash
npm run admin:setup
```

This will:
- Generate a secure password hash
- Create environment files
- Generate Wrangler secrets commands

### 4. Configure Cloudflare Secrets

Run the commands generated by the admin setup script:

```bash
wrangler secret put ADMIN_EMAIL
# Enter your admin email

wrangler secret put ADMIN_PASSWORD_HASH
# Enter the generated password hash

wrangler secret put RESEND_API_KEY
# Enter your Resend API key

wrangler secret put RESEND_FROM_EMAIL
# Enter: hello@alfinamugni.wedding
```

## 🗄️ Database Setup

### 1. Apply Database Migrations

```bash
npm run db:migrate
```

### 2. Verify Database Schema

The deployment script will automatically test database connectivity.

## 🚀 Deployment Process

### 1. Automated Deployment

Use the automated deployment script:

```bash
npm run deploy
```

This script will:
- Install dependencies
- Run tests
- Build the project
- Deploy to Cloudflare Pages
- Provide post-deployment instructions

### 2. Manual Deployment

If you prefer manual deployment:

```bash
# Build the project
npm run build

# Deploy to Cloudflare Pages
wrangler pages deploy dist --project-name alfinamugni-wedding
```

## 🌐 Post-Deployment Configuration

### 1. Custom Domain (Optional)

If you have a custom domain:

1. Go to Cloudflare Pages dashboard
2. Select your project
3. Go to "Custom domains"
4. Add your domain (e.g., alfinamugni.wedding)
5. Update DNS records as instructed

### 2. SSL Certificate

Cloudflare automatically provides SSL certificates for:
- `.pages.dev` domains (immediate)
- Custom domains (after DNS propagation)

### 3. Environment Variables

Ensure these are configured in Cloudflare Pages:

```bash
# Production environment variables
ENVIRONMENT=production
WEDDING_DATE=2025-11-29
TIMEZONE=Asia/Jakarta
WEDDING_LOCATION=Jakarta, Indonesia
EXPECTED_GUESTS=200
BRIDE_NAME=Alfina
GROOM_NAME=Mugni
```

## 🚨 Troubleshooting

### Common Issues

#### Build Failures
```bash
# Clear cache and rebuild
rm -rf node_modules dist
npm ci
npm run build
```

#### Database Connection Issues
```bash
# Check database configuration
wrangler d1 info wedding-database

# Re-run migrations
npm run db:migrate
```

#### Authentication Issues
```bash
# Reset admin credentials
npm run admin:setup

# Clear sessions
wrangler kv:delete --namespace-id=ADMIN_KV --prefix="session:"
```

#### Deployment Failures
```bash
# Check Wrangler authentication
wrangler whoami

# Verify project configuration
wrangler pages project list
```

### Getting Help

1. Check Cloudflare Pages logs
2. Review browser console errors
3. Test API endpoints directly
