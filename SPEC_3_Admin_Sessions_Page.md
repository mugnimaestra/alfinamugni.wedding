## Features Required

### 1. Sessions List Display

**Session Card Component:**
- Session ID (e.g., "wdng-abc123")
- Title & Description
- Active/Inactive badge
- Photo count
- Created date
- Action buttons:
  - Copy Link
  - Show QR Code
  - Toggle Active/Inactive
  - View Photos (link to `/admin/gallery?session=[id]`)

### 2. Create Session Dialog

**Dialog Contents:**
- Title input (required)
- Description textarea (optional)
- Prefix input (default: "wdng", generates unique ID like "wdng-abc123")
- Active checkbox (default: true)
- Cancel button
- Create button

**Flow:**
1. Click "+ New Session" button
2. Dialog opens
3. Fill form
4. Click "Create"
5. POST to `/api/admin/sessions`
6. On success: close dialog, show QR modal for new session
7. On error: show error message

### 3. QR Code Modal

**Modal Contents:**
- Session title
- Session URL (e.g., `https://wedding.com/g/wdng-abc123`)
- QR Code image (generated by API)
- Copy URL button
- Download QR button
- Close button

**QR Code Display:**
- Use QR code from `session.qr_code_url` (generated by API)
- Or generate client-side using `qrcode` library
- Size: 300x300px for display, 1200x1200px for download

### 4. Toggle Active State

**Flow:**
1. Click toggle button on session card
2. PATCH to `/api/admin/sessions/[id]` with `{ is_active: !current }`
3. On success: update card badge, show toast
4. On error: revert toggle, show error toast

### 5. Copy Link Function

**Flow:**
1. Click "Copy Link" button
2. Copy `${window.location.origin}/g/${session.session_id}` to clipboard
3. Show success toast: "Link copied!"

## Data Loading

### `src/routes/admin/sessions/+page.server.ts`

```typescript
import type { PageServerLoad } from './$types';
import { redirect } from '@sveltejs/kit';
import { validateAdminSession } from '$lib/admin-auth';
import { getDatabase } from '$lib/server/database';

export const load: PageServerLoad = async ({ cookies, platform }) => {
  // Check authentication
  const adminSession = cookies.get('admin_session');
  if (!adminSession || !validateAdminSession(adminSession)) {
    throw redirect(302, '/admin/login?returnTo=/admin/sessions');
  }

  if (!platform?.env) {
    return { sessions: [] };
  }

  const db = getDatabase(platform.env);
  const sessions = await db.getAllSessions();

  return {
    sessions: sessions.map(s => ({
      id: s.id,
      session_id: s.session_id,
      title: s.title,
      description: s.description,
      is_active: s.is_active,
      photo_count: s.photo_count || 0,
      created_at: s.created_at,
      qr_code_url: s.qr_code_url
    }))
  };
};
```

## QR Code Generation

**Option 1: Use API-generated QR codes** (preferred)
- QR codes are already generated by `/api/admin/sessions` POST endpoint
- Use `session.qr_code_url` from response

**Option 2: Generate client-side**
- Install: `pnpm add qrcode`
- Generate in browser when showing modal

```typescript
import QRCode from 'qrcode';

async function generateQR(url: string): Promise<string> {
  try {
    return await QRCode.toDataURL(url, {
      width: 300,
      margin: 2,
      color: {
        dark: '#1a202c', // wedding-navy
        light: '#ffffff'
      }
    });
  } catch (err) {
    console.error('QR generation failed:', err);
    return '';
  }
}
```

## Client-Side State Management

```typescript
let sessions = $state<GallerySession[]>([]);
let loading = $state(false);
let isCreateOpen = $state(false);
let qrModalOpen = $state(false);
let selectedSession = $state<GallerySession | null>(null);

async function loadSessions() {
  loading = true;
  const response = await fetch('/api/admin/sessions');
  const result = await response.json();
  if (result.success) {
    sessions = result.sessions;
  }
  loading = false;
}

async function createSession(data: SessionData) {
  const response = await fetch('/api/admin/sessions', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(data)
  });
  
  const result = await response.json();
  if (result.success) {
    await loadSessions();
    selectedSession = result.session;
    qrModalOpen = true; // Show QR immediately after creation
  }
}

async function toggleActive(session: GallerySession) {
  const response = await fetch(`/api/admin/sessions/${session.id}`, {
    method: 'PATCH',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ is_active: !session.is_active })
  });
  
  if (response.ok) {
    await loadSessions();
  }
}

function copyLink(sessionId: string) {
  const url = `${window.location.origin}/g/${sessionId}`;
  navigator.clipboard.writeText(url);
  // Show toast notification
}
```
